# Security Policy

This policy applies to every repository in the `DashinDesign` organization that does not
publish its own `SECURITY.md`.

## Reporting a Vulnerability

**Preferred channel:** GitHub private vulnerability reporting. On the affected repository,
go to the **Security** tab and choose **Report a vulnerability**. This keeps details
confidential between you and the maintainers, and it is the fastest route to a fix.

If that channel is unavailable to you, email: `TO_BE_CONFIGURED` _(configure later —
deliberately deferred)_. Until that address is wired up, please use the GitHub channel
above.

**Please do not open public issues for security vulnerabilities.**

## Response expectations

- Acknowledgement within 48 hours.
- Initial assessment within 7 days.
- Coordinated disclosure: we'll agree on a timeline with you before making any advisory
  public.
- Credit in release notes, unless you prefer anonymity.

## Supported versions

Unless a repository states otherwise, only the latest release on the default branch
receives security fixes. Projects still pre-1.0 fix forward on their development branch
only.
