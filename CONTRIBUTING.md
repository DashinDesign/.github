# Contributing

Build and test instructions live in each repository's own README. This file covers what
applies across the organization.

- Sign off every commit — `git commit -s`, per the
  [DCO](https://developercertificate.org/).
- Use [Conventional Commits](https://www.conventionalcommits.org/).
- Open an issue before anything non-trivial.
- A bug fix ships a regression test that fails without the fix.
- Licensing is per-repository — read the `LICENSE` file before you start.
